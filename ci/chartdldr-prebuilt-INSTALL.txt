Chart Downloader plugin (prebuilt) — fork test build
====================================================

These archives contain only the chartdldr_pi shared library and data/
files from this fork. They replace the bundled plugin in an existing
OpenCPN install. Quit OpenCPN before copying files.

Version: @CHARTDLDR_VERSION@
Git: @GIT_SHA@

Linux (amd64 or arm64)
----------------------
1. Unzip the archive.
2. Copy libchartdldr_pi.so into your OpenCPN plugin directory, for example:
     ~/.local/lib/opencpn/plugins/
   or the path shown in Help → About → Plugin folder.
3. Copy the chartdldr_pi/ tree (data and translations) next to other plugins:
     ~/.local/share/opencpn/plugins/chartdldr_pi/
   Layout in the zip matches that share/plugins/chartdldr_pi/ tree.

Windows
-------
1. Unzip the archive.
2. Copy chartdldr_pi.dll into:
     C:\Program Files\OpenCPN\plugins\
   (or your install location).
3. Copy the chartdldr_pi\ folder into:
     C:\Program Files\OpenCPN\plugins\chartdldr_pi\

macOS
-----
1. Unzip the archive.
2. Right-click OpenCPN.app → Show Package Contents.
3. Replace:
     Contents/PlugIns/libchartdldr_pi.dylib
4. Merge/replace:
     Contents/SharedSupport/plugins/chartdldr_pi/
   with the chartdldr_pi folder from the zip.

Android and Flatpak
-------------------
Not built by this workflow. Use a matching desktop build or build from
source (buildandroid / flatpak) on this branch.

Compatibility
-------------
Built against the OpenCPN tree on this branch. Use a recent OpenCPN 5.x
build with plugin API 1.18 (opencpn_plugin_113). ABI mismatches show up
as load failures in the Plugins list.
